# Coding Agent

Приложение для создания веб-приложений через чат. Агент использует один инструмент — bash. Каждое приложение запускается в отдельном Docker-контейнере.

## Запуск

Требуется Docker с Docker Compose.

```bash
cp .env.example .env
docker compose up --build -d
```


Настройки LLM находятся в `.env`.

- Интерфейс: http://localhost:8080.
- Backend: http://localhost:8082/api/chats.

## Структура

- `backend/` — API, агент, история чатов и управление контейнерами.
- `frontend/` — чат и предпросмотр.
- `app-template/` — Next.js-шаблон создаваемых приложений.
- `customer-db/` — тестовая база заказчика с каталогом товаров.

После изменения кода повторите команду запуска. История и файлы приложений сохраняются между перезапусками.

## Тестовая база заказчика

В схеме `catalog` есть таблицы `categories` (5 категорий) и `products` (100 товаров с ценами, остатками и признаком активности).

- Из контейнера создаваемого приложения: `customer-db:5432`.
- С компьютера: `localhost:5434`.
- База, пользователь и пароль: `customer`.
